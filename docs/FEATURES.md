# Apex Legends Performance Tuner — feature reference

Apex Legends Performance Tuner brings display profiles and frame pacing notes into one section-based interface. Test sessions provides the third part of the workflow.

| Section | Description |
|---|---|
| Display profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Frame pacing notes | Display or performance-related options, with space for configuration and comparison information. |
| Test sessions | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
